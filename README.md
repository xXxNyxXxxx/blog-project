# Blog Project

A personal blogging web application built with Flask, SQLAlchemy, Bootstrap, and CKEditor.

## Features
* User authentication (Register, Login, Logout)
* Admin-only privileges for creating, editing, and deleting posts
* Commenting system on blog posts
* SQLite database storage
